# مستحقات برامج الراديو

موقع عربي لتسجيل مشاركات المقدمين والشيوخ، مراجعتها من المراقبين والإدارة العليا، وحساب المستحقات الشهرية.

## الأسعار المبرمجة

| نوع البرنامج | المقدم / المقدمة | الشيخ |
|---|---:|---:|
| مسجل | 100 د.ل للساعة | 150 د.ل للساعة |
| مباشر | 40 د.ل للساعة | 75 د.ل للساعة |

تُحسب المدة بالدقائق. تضاف أسماء البرامج من حساب الإدارة العليا، ويختار المستخدم البرنامج من القائمة عند التسجيل. يشمل الكشف الرسمي المشاركات المعتمدة فقط، وتبقى حالة كل مشاركة ظاهرة لصاحب الحساب.

## الصلاحيات

- **الإدارة العليا:** حساب الدخول المحدد بمتغيرات البيئة؛ يراجع الطلبات، يدير البرامج والحسابات، يعيّن المراقبين، ويصدر الكشوف الشهرية.
- **المراقب:** حساب مقدم أو شيخ تنشئه الإدارة العليا ثم تغيّر صلاحيته؛ يراجع الطلبات ويعتمدها أو يرفضها.
- **المقدم أو الشيخ:** ينشئ حساباً عادياً، ويسجل المشاركات، ويشاهد سجل الشهر وحالة المراجعة والمستحقات المعتمدة الخاصة به.

توفر الإدارة العليا طباعة إجمالية مجمعة حسب البرنامج، وطباعة مفصلة تتضمن تاريخ البرنامج والتسجيل والمراجعة واسم المعتمد والتفاصيل المالية. تصدير Excel متاح بصيغة CSV متوافقة مع Excel.

## التشغيل

يتطلب Node.js 20 أو أحدث، ولا يحتاج إلى تثبيت حزم إضافية.

في PowerShell:

```powershell
$env:ADMIN_USERNAME = "admin"
$env:ADMIN_PASSWORD = "ضع-هنا-كلمة-مرور-بطول-8-أحرف-على-الأقل"
npm start
```

افتح `http://localhost:3000`. دخول الإدارة يكون باسم المستخدم وكلمة المرور اللذين عيّنتهما. اسم المستخدم الافتراضي `admin`. ينشئ المقدمون والشيوخ حساباتهم من صفحة إنشاء الحساب.

تُحفظ الحسابات والطلبات في `data/records.json` على الخادم. احتفظ بنسخة احتياطية من هذا الملف، ولا تنشره للعموم. عند النشر على الإنترنت، استخدم HTTPS، وكلمة مرور إدارة قوية، واستضافة تحفظ مجلد `data` عند إعادة التشغيل.

## النشر للتجربة عبر GitHub وRender

ملف `render.yaml` يجهز الموقع كخدمة Node على Render. GitHub Pages لا يناسب هذا المشروع؛ لأن تسجيل الدخول والحسابات تحتاج إلى خادم.

1. أنشئ مستودعاً جديداً على GitHub، ثم ارفع ملفات المشروع إليه. لا ترفع كلمات المرور أو مجلد `data`.
2. في Render اختر **New → Blueprint** واربط حساب GitHub والمستودع. سيقرأ Render إعدادات `render.yaml`.
3. عند طلب قيمة `ADMIN_PASSWORD`، أدخل كلمة مرور الإدارة كـ **Secret** في لوحة Render؛ لا تكتبها في ملف أو مستودع GitHub. اسم المستخدم مضبوط على `MALEK` ويمكن تغييره من متغير `ADMIN_USERNAME`.
4. بعد اكتمال النشر، افتح رابط الخدمة الذي يعطيك إياه Render وشاركه مع زميلك للتجربة. يمكن دخول الإدارة باسم المستخدم وكلمة المرور المضبوطين، بينما ينشئ زميلك حساب مشارك من الصفحة.

**تنبيه للتجربة فقط:** إعداد Render المجاني يستخدم تخزيناً مؤقتاً؛ قد تضيع الحسابات والتسجيلات عند إعادة تشغيل الخدمة أو إعادة نشرها. لا تستخدمه لحفظ مستحقات حقيقية أو بيانات حساسة. للاستخدام الفعلي نحتاج تخزيناً دائماً وقاعدة بيانات ونسخاً احتياطية.

## سير العمل

1. ينشئ كل مقدم أو شيخ حساباً بصفته، ثم يسجل كل مشاركة باسمه والبرنامج والمشارك الآخر والتاريخ والمدة ونوع البث.
2. يراجع المسؤول الطلب ويعتمده أو يرفضه. الطلبات المعلقة والمرفوضة لا تدخل في الكشف.
3. يعرض كشف الإدارة مجموع المستحقات المعتمدة حسب الفترة، ويمكن تصديره بصيغة CSV المتوافقة مع Excel أو طباعته.
